PORTFÓLIO — VERSÃO COM SOM E FUNDO CINEMATOGRÁFICO

1. Abra index.html no navegador para visualizar.
2. Na seção Projetos, clique em “Ativar som”. Por regra dos navegadores, o áudio só começa após essa interação.
3. Apenas o projeto em destaque toca áudio; os demais permanecem pausados e mudos.
4. O fundo agora possui partículas, malha em perspectiva, halos luminosos e parallax leve.
5. Em celulares e em dispositivos com “reduzir movimento”, os efeitos são simplificados para preservar desempenho.
6. Para atualizar no GitHub Pages, substitua todos os arquivos, incluindo assets/videos.
